## Bug #1：float64 timeout 精度丢失

**文件：** [sandbox/bubblewrap.go](file:///home/joshua/Downloads/inferglow-workdir/inferglow/sandbox/bubblewrap.go) — 第 92 行

**失败测试：** `TestParseBubblewrapConfigTimeout`

**问题描述：**
`parseBubblewrapConfig` 解析 `timeout_seconds` 时，`float64` case 使用 `time.Duration(d) * time.Second`，其中 `time.Duration` 是 `int64` 类型。当输入 `float64(2.5)` 时，`time.Duration(2.5)` 截断为 `2`，最终得到 `2s` 而非 `2500ms`。

```go
// 修复前（错误）
case float64:
    out.Timeout = time.Duration(d) * time.Second  // 2.5 → 2s ❌

// 修复后（正确）
case float64:
    out.Timeout = time.Duration(d*float64(time.Second))  // 2.5 → 2500ms ✅
```

**根因：** `float64` → `int64` 隐式转换丢失小数部分。

## Bug #2：parseTmpfsMap 未知类型返回空 map 而非 nil

**文件：** [sandbox/bubblewrap.go](file:///home/joshua/Downloads/inferglow-workdir/inferglow/sandbox/bubblewrap.go) — 第 160-187 行

**失败测试：** `TestParseTmpfsMapUnknownType`

**问题描述：**
当输入不是 `map[string]int`、`map[string]int64` 或 `map[string]any` 中的任何一种（例如 `string`、`int`、`nil` 之外的类型）时，`switch` 没有匹配的 case，函数末尾执行 `return out`，返回一个初始化的空 map `map[string]int64{}` 而非 `nil`。

测试期望：非预期类型应返回 `nil`。

```go
// 修复前（错误）
func parseTmpfsMap(v any) map[string]int64 {
    if v == nil {
        return nil
    }
    out := map[string]int64{}  // 已初始化
    switch t := v.(type) {
    case map[string]int:
        // ... return out
    case map[string]int64:
        // ... return out
    case map[string]any:
        // ... return out
    }
    return out  // ❌ 未知类型返回空 map，应为 nil
}

// 修复后（正确）
func parseTmpfsMap(v any) map[string]int64 {
    if v == nil {
        return nil
    }
    out := map[string]int64{}
    switch t := v.(type) {
    case map[string]int:
        for k, val := range t {
            out[k] = int64(val)
        }
        return out  // ✅ 每种 case 显式 return
    case map[string]int64:
        for k, val := range t {
            out[k] = val
        }
        return out  // ✅
    case map[string]any:
        for k, val := range t {
            switch n := val.(type) {
            case int:
                out[k] = int64(n)
            case int64:
                out[k] = n
            case float64:
                out[k] = int64(n)
            }
        }
        return out  // ✅
    }
    return nil  // ✅ 未知类型返回 nil
}
```

**根因：** switch 没有为每个 case 显式 return，所有 case 执行完后落入末尾的 `return out`，此时 `out` 是已初始化的空 map。

## Bug #3：parseStringMap 未知类型返回空 map 而非 nil

**文件：** [sandbox/e2b.go](file:///home/joshua/Downloads/inferglow-workdir/inferglow/sandbox/e2b.go) — 第 107-130 行

**失败测试：** `TestParseStringMapUnknownType`

**问题描述：**
与 Bug #2 相同的模式。`parseStringMap` 在输入不是 `map[string]string` 或 `map[string]any` 时（如 `int(42)`），落入 switch 末尾返回空 map 而非 `nil`。

```go
// 修复前（错误）
func parseStringMap(v any) map[string]string {
    if v == nil {
        return nil
    }
    out := map[string]string{}
    switch t := v.(type) {
    case map[string]string:
        for k, v := range t {
            out[k] = v
        }
    case map[string]any:
        for k, v := range t {
            // ...
        }
    }
    return out  // ❌ 未知类型返回空 map
}

// 修复后（正确）
func parseStringMap(v any) map[string]string {
    if v == nil {
        return nil
    }
    out := map[string]string{}
    switch t := v.(type) {
    case map[string]string:
        for k, v := range t {
            out[k] = v
        }
        return out  // ✅
    case map[string]any:
        for k, v := range t {
            switch s := v.(type) {
            case string:
                out[k] = s
            case fmt.Stringer:
                out[k] = s.String()
            default:
                out[k] = fmt.Sprintf("%v", v)
            }
        }
        return out  // ✅
    }
    return nil  // ✅
}
```

**根因：** 与 Bug #2 完全相同的 switch 兜底问题。

## 修复总结

| # | 文件 | 函数 | 问题 | 修复方式 |
|---|------|------|------|---------|
| 1 | `bubblewrap.go:92` | `parseBubblewrapConfig` | float64 → int64 截断 | `time.Duration(d*float64(time.Second))` |
| 2 | `bubblewrap.go:160-187` | `parseTmpfsMap` | 未知类型返回空 map | 每 case 显式 `return out`，末尾 `return nil` |
| 3 | `e2b.go:107-130` | `parseStringMap` | 未知类型返回空 map | 每 case 显式 `return out`，末尾 `return nil` |

**修复模式：** 对于返回 map 类型的解析函数，当输入为未知类型时应返回 `nil` 而非空 map。关键修复方式：
1. 为每个 `switch` case 添加显式 `return out`
2. switch 末尾添加 `return nil` 作为兜底
